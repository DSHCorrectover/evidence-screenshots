拟在扣子技能商店上架三款 AI Agent 安全方向的开发者工具技能，面向 AI Agent / MCP 开发者与安全审计人员：

1. CCS收据验签（Ed25519 签名防篡改审计）：对 AI Agent 决策/工具调用产生的 CCS 审计收据做密码学验签（Ed25519 + RFC8785 JCS 规范化 + SHA-256 完整性重算），确认收据签发后未被篡改、未被伪造，验证不通过 fail-closed 拦截。
2. MCP配置安全体检：挂载 MCP 服务器前对 mcpServers 配置做 14 项静态安全检查（云密钥硬编码、任意命令执行、可写文件系统挂载、SSRF 出网面、明文 HTTP、危险工具聚类等），按 CRIT/HIGH/MED/LOW 四级输出发现与修复建议，纯静态分析不连接配置地址。
3. CCS收据批量审计：批量验签最多 200 张收据，输出有效/无效统计、篡改收据索引与逐条失败原因，支持哈希链检查。

典型使用方式：开发者在 Agent 中安装技能后，直接贴入收据或 MCP 配置即可获得审计结果。技能调用后端验证 API 提供服务，核心验证逻辑开源（Elastic-2.0 许可证），拟采用按次付费模式。
